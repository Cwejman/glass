# What is new

Today AI reaches into computing through harnesses: sessions, prompts, tool wrappers, permission dialogs and cloud APIs, each making up for primitives that are missing. Data is locked inside apps, context is rebuilt for every session, and safety is policed from outside.

What is new is a simple set of primitives. Data, types, programs, AI and interfaces are one field of whole pieces. Programs match the data they fit by type, and every effect passes through the field, visible and bounded. Interfaces compose themselves the same way.
