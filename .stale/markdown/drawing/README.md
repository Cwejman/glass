# How this is drawn

Nothing here is written as a page. A holon that holds drawing code is a drawer, and a holon that holds a layout is an arrangement: a tree of mounts, each naming a drawer and the holon it is handed. The site and the CV are two arrangements over one holarchy, and changing how either looks is an edit to a holon like any other.

No holon is given a kind. What a drawer takes is said as what a holon holds, and a drawer handed a holon without it says so in place rather than guessing.

[Home](home.md) draws the root as the first page anyone meets.

[The site](site.md) draws every holon on its own page.

[The CV](cv.md) draws the root on one sheet, for paper.

[The drawers](drawers/README.md) are what both are made of.
